🎯 按需引入示例

说明： 按需引入需要使用构建工具（如 Vite、Webpack）配合 ES Modules 使用。
此示例展示了在 Vue SFC (Single File Component) 中如何按需引入组件。

使用方式

<script setup>
// 只导入需要的组件
import { Button, EnhancedButton } from '@vue-lib/components'
import '@vue-lib/components/style.css'
</script>

<template>
  <div>
    <!-- 直接使用导入的组件 -->
    <Button type="primary">基础按钮</Button>
    <EnhancedButton type="success">增强按钮</EnhancedButton>
  </div>
</template>

优势

  • ✅ Tree Shaking：未使用的组件不会被打包
  • ✅ 按需加载：只加载需要的组件代码
  • ✅ 减小体积：最终打包文件更小
  • ✅ 性能优化：减少初始加载时间

实际项目示例

// src/components/MyComponent.vue
<script setup lang="ts">
import { ref } from 'vue'
import { EnhancedButton } from '@vue-lib/components'
import '@vue-lib/components/style.css'
import { Search } from '@element-plus/icons-vue'

const loading = ref(false)

const handleSearch = () => {
  loading.value = true
  // 执行搜索逻辑...
  setTimeout(() => loading.value = false, 2000)
}
</script>

<template>
  <EnhancedButton 
    type="primary"
    :icon="Search"
    :loading="loading"
    @click="handleSearch"
  >
    搜索
  </EnhancedButton>
</template>

TypeScript 支持

// 完整的类型提示
import type { Component } from 'vue'
import { Button, EnhancedButton } from '@vue-lib/components'

// 组件类型会自动推导
const MyButton: typeof Button = Button
const MyEnhancedButton: typeof EnhancedButton = EnhancedButton

配置建议

Vite 项目： 无需额外配置，开箱即用支持 Tree Shaking

// vite.config.ts
export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        manualChunks: {
          // 可选：将组件库单独打包为一个 chunk
          'vue-lib': ['@vue-lib/components']
        }
      }
    }
  }
})
